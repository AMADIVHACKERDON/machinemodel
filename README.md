# Machine Learning Models with TensorFlow

A collection of machine learning experiments built with **Python** and **TensorFlow/Keras** to explore the fundamentals of neural networks, deep learning, and model evaluation.

This repository contains implementations of different machine learning concepts including dense neural networks, activation functions, loss functions, and handwritten digit recognition using the MNIST dataset.

---

## 📌 Project Objectives

- Learn the fundamentals of Machine Learning.
- Build neural network models using TensorFlow/Keras.
- Understand activation functions and dense layers.
- Experiment with different loss functions such as Mean Squared Error (MSE).
- Train and evaluate image classification models.

---

## 🚀 Features

- Neural Network implementation
- Dense Layer examples
- Activation Function demonstrations
- Mean Squared Error (MSE) examples

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/AMADIVHACKERDON/machinemodel.git
```

Move into the project

```bash
cd machinemodel
```

Install dependencies

```bash
pip install tensorflow numpy matplotlib
```

---

## ▶ Running the Project

Run any Python file individually.

Example:

```bash
python NN_ML.py
```

or

```bash
python Dense_embeddLayer.py
```
